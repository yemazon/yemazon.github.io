# Yezhong Xu — Engineering Portfolio

Public portfolio for selected backend and AI/LLM systems work.

The case studies use generalized architecture diagrams and deliberately omit proprietary service names, data contracts, model-routing details, internal screenshots, customer information, and company-specific controls.

## Local preview

Serve the repository as a static site and open `index.html` through the local server. No build step is required.

## Content policy

- Describe engineering decisions and reusable system patterns.
- Use only metrics that are approved for public professional use.
- Redraw architecture diagrams with generic component names.
- Never commit internal documents, screenshots, prompts, schemas, logs, identifiers, or incident details.
